# Nibras Promo Video Draft

## Goal

Make a simple, friendly promo that shows Nibras working on the real Learnmates website. Record the screen while using the features; add the short voiceover afterward if recording live feels difficult.

**Suggested length:** 60–75 seconds  
**Format:** 16:9 horizontal video  
**Style:** Clear screen recording, steady cursor, readable text, no fast edits

## Before You Record

1. Sign in to Learnmates and make sure Nibras is available on the account.
2. Choose a supported subject and prepare one short question for the chat.
3. Open a supported Physics, Chemistry, or Biology topical question with its answer or mark scheme available. Pick a question that makes the explanation easy to follow.
4. Close unrelated tabs and notifications. Set browser zoom so the question and Nibras controls are readable.
5. Do a quick test recording. Avoid showing personal details, private chats, or account information.
6. If the welcome or disclosure dialog appears, dismiss it before recording the feature demo.

## Recording Tips

- Record the website itself rather than recreating the interface. Use a clean browser window and move the cursor deliberately.
- Pause after sending a prompt and after clicking **Explain** so the audience can read the answer. Trim waiting time during editing.
- Keep each prompt short and use a real supported question. Don’t imply that Nibras is always correct or supports every subject.
- Captions are helpful, especially if the video will be viewed without sound.
- Use only music and graphics you have permission to publish. Keep music quiet under the voiceover.
- If you don’t want to narrate, use the voiceover column as on-screen captions instead.
